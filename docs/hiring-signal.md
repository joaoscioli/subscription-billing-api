# Hiring Signal

This repository is meant to support hiring conversations for backend roles that
need API design, domain modeling, and production-minded engineering.

## What It Proves

- Ability to reason about a money-related domain before coding too broadly.
- Awareness of state, idempotency, auditability, observability, and testing.
- Communication of architecture decisions in a reviewable format.

## Role Fit

Best aligned with Java backend, Spring Boot, REST API, platform, and SaaS product
engineering roles where correctness and maintainability matter.
