# Technical Scope

This file defines what the project is meant to prove and what it does not claim yet.

## In Scope

- Subscription lifecycle modeling.
- REST API contract design.
- Billing and payment boundary planning.
- Testing, documentation, and production-readiness thinking.

## Out of Scope for Now

- Real payment-provider processing.
- Full production authorization enforcement.
- Live deployment and operational dashboards.
- Multi-service billing decomposition.

## Scope Statement

The project is scoped to prove backend design maturity first. The next milestone
is implementing a complete lifecycle slice that turns the documented boundaries
into executable behavior.
