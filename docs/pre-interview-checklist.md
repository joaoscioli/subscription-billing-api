# Pre-Interview Checklist

Use this checklist before presenting the repository.

## Review Before The Call

- Open the fast review path and interview case study.
- Prepare one subscription lifecycle example from creation to renewal or cancellation.
- Know which tests prove the API and domain behavior.
- Be ready to explain why this project is a modular monolith.

## Be Ready To Show

- `SubscriptionService`
- `SubscriptionControllerTests`
- lifecycle ADRs
- API overview and observability notes

## Strong Close

Explain that the next senior step is invoice read models connected to renewals.
