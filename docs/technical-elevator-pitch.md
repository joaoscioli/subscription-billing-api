# Technical Elevator Pitch

This project is a backend architecture case study for subscription billing. It
focuses on modeling the subscription lifecycle, separating billing rules from
payment-provider details, and preparing the system for testable, auditable,
idempotent operations.

## 30-Second Version

"I built this repository to show how I reason about a money-related backend
before rushing into external payment integration. The main signal is the
architecture: clear domain boundaries, explicit lifecycle states, risk mapping,
test strategy, acceptance criteria, and a path toward an executable Spring Boot
API."
