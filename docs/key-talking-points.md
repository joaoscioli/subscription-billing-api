# Key Talking Points

Use these points to keep the interview conversation focused.

## Lead With

- The project models a SaaS billing workflow, not only CRUD resources.
- The subscription lifecycle is the strongest vertical slice.
- Audit events make important business transitions reviewable.

## Go Deeper On

- Why a modular monolith fits this portfolio project.
- How API tests and domain tests protect different risks.
- Why invoice read models are the next meaningful improvement.

## Avoid Overclaiming

- Do not present this as a production billing platform.
- Present it as a compact backend project that demonstrates engineering
  judgment, domain modeling, and production-minded structure.
