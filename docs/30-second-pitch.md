# 30-Second Pitch

This project is a SaaS billing backend built with Java and Spring Boot.

It demonstrates how I model a realistic business workflow instead of only
building CRUD endpoints. The strongest part is the subscription lifecycle:
plans, customers, subscriptions, renewals, cancellations, persistence, tests,
audit events, and documentation are connected in one reviewable vertical slice.

In an interview, I would use this repository to discuss backend architecture,
domain modeling, API contracts, database migrations, test strategy, and
production readiness.
