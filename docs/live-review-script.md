# Live Review Script

Use this script when sharing the repository during an interview.

## Opening

This project models a subscription billing API with attention to domain boundaries, authentication, testing, and production readiness.

## Walkthrough order

1. Start with `README.md` to set the business context.
2. Open `docs/architecture.md` to explain modular boundaries.
3. Use `docs/decisions/` to show architectural reasoning.
4. Show `docs/test-strategy.md` and API/authentication notes.
5. Close with `ROADMAP.md` to explain the next implementation slice.

## Strong signal

The repository is structured to show how I reason about backend systems before coding every endpoint.
