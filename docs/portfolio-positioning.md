# Portfolio Positioning

This is the primary backend project in the portfolio.

## What It Proves

- Java and Spring Boot API ownership.
- Domain modeling around a realistic SaaS billing workflow.
- Persistence, migrations, validation, tests, and documentation moving together.
- Production awareness through CI, observability, release notes, and quality gates.

## How To Present It

Present this repository as the main evidence that you can take a backend feature
from product scope to implementation, testing, documentation, and operational
readiness.

## Best Interview Angle

Start with the subscription lifecycle and explain how each layer supports the
same business workflow.
