# Hiring Manager Summary

This repository is the strongest backend portfolio project.

## Why It Matters

It shows Java and Spring Boot ownership through a realistic SaaS billing API
instead of isolated code snippets.

## What To Notice

- Clear product scope and documented out-of-scope decisions.
- Subscription lifecycle implemented with API, persistence, tests, and audit history.
- CI, quality gates, observability, and release documentation.
- ADRs that explain architectural choices.

## Interview Signal

This project is useful for discussing backend architecture, domain modeling,
testing strategy, API design, and production readiness.
